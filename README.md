# AGRICEF — Dashboard de Produção

Dashboard interativo para acompanhamento em tempo real dos apontamentos de produção da AGRICEF.

## 🔗 Acesso

**[➡️ Abrir Dashboard](https://agricefprocessos-tech.github.io/agricef-dashboard/)**

## Funcionalidades

- KPIs de produção (pares calculados, throughput, lead time, eficiência)
- Análise por funcionário, operação, série e item
- Backlog de ordens abertas com fechamento pelo líder
- Tendência histórica de 4 semanas
- Auditoria de inconsistências
- Exportação para CSV
- Configuração de custo por hora

## Tecnologia

- HTML/CSS/JS puro (sem dependências externas além do Chart.js)
- Backend: Google Apps Script + Google Sheets
- Dados atualizados automaticamente a cada 5 minutos
